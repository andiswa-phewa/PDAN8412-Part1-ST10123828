# PDAN8412 Part 1: Author Identification Using LSTM

## Project Overview

This project forms Part 1 of the PDAN8412 Programming for Data Analytics 2 Portfolio of Evidence.

The aim of the project is to build a text classification model that predicts the most likely author of a passage based on writing style. The analysis uses the TextAge historical text corpus from Kaggle.

Apache Spark is used for loading, cleaning and exploring the dataset. PyTorch is used to build and train the LSTM models.

## Dataset

The project uses the TextAge historical text corpus from Kaggle.

The downloaded large dataset contains 91,918 records. Seven frequent named authors were selected for modelling. After cleaning, the final modelling dataset contains 13,149 records.

The selected authors are:

- Charles Dickens
- William Caxton
- Anthony Trollope
- William Shakespeare
- Daniel Defoe
- Rudyard Kipling
- Elizabeth Cleghorn Gaskell

## Main Analysis Steps

The notebook includes:

- dataset loading with PySpark
- data quality checks
- missing value and duplicate checks
- exploratory data analysis
- author and title distribution analysis
- text length analysis
- work-aware train, validation and test splitting
- text tokenisation and vocabulary creation
- baseline LSTM training
- improved bidirectional LSTM training
- validation model comparison
- final test evaluation
- confusion matrix analysis
- a simple author prediction function

The train, validation and test split is performed at author and title level to reduce data leakage between passages from the same literary work.

## Model Results

The improved Bidirectional LSTM was selected based on validation macro F1.

Final test results:

- Accuracy: 43.91%
- Macro Precision: 44.28%
- Macro Recall: 47.79%
- Macro F1: 44.29%
- Balanced Accuracy: 47.79%

William Caxton achieved the strongest author-level F1 score, while Daniel Defoe was the weakest performing class.

## Running the Notebook

Before running the notebook, ensure that Java 17, PySpark and the required Python libraries are installed.

Launch Jupyter Notebook from the project folder, open the `.ipynb` file and run the cells from top to bottom.

The notebook automatically extracts the required CSV file from `archive.zip` if it has not already been extracted.

## Notes

The model is intended as a prototype author-guessing application and not as a forensic authorship identification system.

The final model can only predict one of the seven authors used during training. Historical period, vocabulary, topic and writing style may all influence the predictions.
